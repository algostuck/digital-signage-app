# UI/UX Screen Redesign Matrix — Digital Signage Cloud

Companion to [UI_UX_AUDIT.md](UI_UX_AUDIT.md). One row per route group.
Originally authored as the pre-implementation plan; all rows are now
**Done** (2026-08-30) — the Target Design column describes the intent, and
per-screen deviations (where the implementation chose a better fit) are
tracked in [UI_UX_IMPLEMENTATION_STATUS.md](UI_UX_IMPLEMENTATION_STATUS.md).

Priority order follows the brief's ladder (App Shell/Login/Dashboard → P1
core workflows → P2 operational screens → P3 secondary/admin screens).
